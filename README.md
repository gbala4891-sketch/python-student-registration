# Student Registration Form

## Project Overview
This project is a simple Student Registration Form developed using Python and Tkinter. It allows users to enter student details and displays a confirmation message after successful registration.

## Technologies Used
- Python
- Tkinter (GUI)

## Features
- Enter student name, age, course, and email.
- Validate required fields.
- Check whether the entered age is valid.
- Display registration confirmation.

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run the following command:

```bash
python student_registration.py
```

## Learning Outcomes
- Understanding Python functions and variables.
- Creating a graphical user interface using Tkinter.
- Using conditional statements for input validation.
- Displaying messages using message boxes.
